What does “lazy matching” mean?Explanation and examples

Lazy matching (non-greedy): to satisfy the complete expression, repetition first tries the lowest allowed number of repetitions; if later rules fail, it increases that number and tries again.

Greedy matching tries more repetitions first and backtracks when needed. This table compares only the first match, without start or end anchors:

Test textGreedy (default)Lazy
aaaaa+ → aaaaa+? → a
<a>one</a><b>two</b><.*> → the entire text<.*?> → <a>

Lazy matching still respects repetition limits: {3}? still matches exactly 3 times. If the complete expression must reach the end, ^a+?$ against aaaa must still match all 4 a characters. Lazy matching is not necessarily faster.

/pattern/u The slashes delimit a JavaScript regex literal; u enables Unicode mode. Enter only the pattern in the source editor, and choose the output language on the right.
The reference below uses JavaScript syntax. This builder supports g, i, m, s, and u. Advanced flags such as d, y, and v require a JavaScript environment that supports them.
