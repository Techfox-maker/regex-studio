# Regex Studio 20261022-v0.0.1

Initial release of the offline-capable visual regular expression builder.

## Included

- Thirteen visual rule types, seven repetition modes, explicit ranges and lazy quantifiers. Drag to reorder rules, move them with buttons, undo edits, or edit regex source directly.
- Forty-five searchable templates with examples, limitations and reference links. Loaded templates become editable visual starting points.
- Sixty-four syntax reference entries covering groups, alternatives, assertions, backreferences, Unicode and flags.
- Live line validation and full-text search. Actual matches appear in green; supported diagnostics identify invalid characters and explain missing content separately.
- Export expressions and usage snippets for JavaScript, Python, Java, C#, grep, sed, awk and Bash, with explicit checks for unsupported conversions.
- English and Simplified Chinese interfaces. Switching languages preserves rules, input, regex source, flags and export settings.
- A standalone HTML page containing all runtime resources. Editing state stays in local browser storage; input text is not uploaded.

## Automated publication

The release process verifies the version, annotated tag, stable history and English
release notes before publication. GitHub Actions runs the source tests, builds the
standalone page, publishes the HTML as the only release asset, downloads it and
checks that its bytes match the artifact built in the same run.

A manual recovery workflow can publish an existing annotated release tag that has
no GitHub Release, using the same validation and artifact checks. Existing Releases
and assets are not overwritten. See `docs/releasing.md` for the release procedure.

## Use

Download `regex-studio.html` from this release and open it in a modern browser.
The generated page works offline and does not require Node.js or a local server.

For source development, use a modern Node.js installation and run these commands
from the repository root. No package installation is needed.

~~~powershell
# Run the built-in test suite under tests/.
node --test

# Build and validate the standalone HTML page in outputs/.
node scripts/build.mjs

# Preview src/ on loopback port 4173; stop with Ctrl+C.
node scripts/serve.mjs
~~~

## Known limits

- Live results use JavaScript RegExp. Other regex engines differ; check exported code in its target environment. Templates validate documented formats, not real-world validity or deliverability.
- Character diagnostics are approximate. Equally plausible corrections may exist. Unsupported assertions, references or excessive complexity leave uncertain text neutral; actual matching remains independent of diagnostics.
- Input is limited to 10,000 characters and full-text results to 500 matches. Worker execution has a time limit. Input and line results use ten-row scrolling viewports.
- The optional native GNU integration check requires explicit opt-in in a compatible environment. Browser rendering and interactive behavior are separate verification steps and are not established by Node tests or a successful build alone.
